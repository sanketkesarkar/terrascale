Three repos working together — Terraform provisions the cloud, Node.js runs the API, serverless handles async events.

Node.js REST API on Compute Engine with Sequelize ORM, auto-startup scripts, and HTTP load balancer.

Managed MySQL database connected through private networking to the application tier.

Object storage for application assets and deployment artifacts.

Async event pipeline between the REST API and serverless functions. Decoupled, scalable messaging.
